# Ben Umbrino Portfolio

This folder is ready for GitHub Pages.

## Publish it

1. Create a new public GitHub repository.
2. Upload every file and folder from this package to the repository root.
3. Confirm that `index.html`, `styles.css`, `script.js`, and the `assets` folder are visible at the top level.
4. Open the repository's **Settings**, then **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the **main** branch and **/(root)** folder, then save.

GitHub will display the live address in the Pages settings after deployment finishes.

## Updating the site later

Replace the changed files in the repository and commit them to the main branch. GitHub Pages will automatically publish the new version.
